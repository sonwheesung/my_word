## [0.0.1] - 개발 중

### 2026-08-05
- **수정**: 단어 공유 CSV 라운드트립 데이터 유실
  - 메모/예문의 줄바꿈을 큰따옴표로 감싸 내보내지만, 파서가 파싱 전에 `\n` 으로
    줄을 먼저 쪼개 내용이 잘리고 없는 에러 행이 표시되던 문제
  - 따옴표를 인식하는 레코드 분리기(`splitCSVRecords`) 도입. CRLF, 미닫힌 따옴표 방어 포함
  - 예문 `::` 구분자를 첫 번째 것만 사용하도록 변경해 뒷부분 유실 제거
  - 내보내기 포맷은 변경하지 않아 구버전 앱과 상호 호환 유지
- **수정**: 활동 히트맵/스트릭이 하루 밀리던 문제
  - 집계가 UTC 문자열을 그대로 잘라 써서 KST 오전 0~9시 활동이 전날로 기록되고
    스트릭이 근거 없이 끊기던 문제
  - `src/utils/date.ts` 추가, 집계 시점에만 기기 로컬 시간대로 환산
  - 저장 포맷(ISO-8601 UTC)은 그대로라 기존 사용자 기록이 마이그레이션 없이 소급 교정됨
- **추가**: 회귀 테스트 29건 (CSV 라운드트립 퍼즈, 날짜 집계, 스트릭 경계)
  - `jest.setup.js` 로 테스트 시간대를 KST 고정, AsyncStorage 목 공용화
