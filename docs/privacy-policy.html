개인정보처리방침

My Word (패키지명: com.myword.front)

1. 개인정보의 수집 및 이용 목적

My Word(이하 "앱")는 사용자의 단어 학습을 돕기 위한 목적으로 개발된 애플리케이션입니다. 본 앱은 별도의 회원가입 없이 사용 가능하며, 계정을 만들거나 이름·이메일·전화번호 등 사용자를 식별할 수 있는 정보를 수집하지 않습니다.

학습 데이터는 기기 안에만 저장됩니다. 다만 사용자가 직접 실행한 경우에 한해 아래 두 기능에서만 외부로 데이터가 전송됩니다: 단어 검색(제5항), 문의하기(제6항).

2. 기기에만 저장되는 데이터

본 앱은 다음과 같은 데이터를 기기 내부(로컬)에만 저장합니다:

  • 사용자가 등록한 단어, 뜻, 예문, 태그, 메모
  • 카테고리 정보
  • 퀴즈 결과 및 학습 통계
  • 앱 설정 (테마 등)

위 데이터는 모두 기기의 AsyncStorage(로컬 저장소)에만 저장되며, 외부 서버로 전송되지 않습니다.

3. 개인정보의 제3자 제공

본 앱은 사용자의 개인정보를 제3자에게 제공하지 않습니다.

4. 광고 서비스

본 앱은 Google AdMob을 통해 광고를 제공합니다. AdMob은 광고 제공을 위해 기기의 광고 식별자(GAID)를 수집할 수 있습니다. 이에 대한 자세한 사항은 Google 개인정보처리방침을 참고해 주세요.

5. 외부 API 사용

단어 검색 기능 사용 시 다음 외부 API에 검색어가 전송될 수 있습니다:

  • Google Translate API (번역 기능)
  • Free Dictionary API (사전 검색)

해당 API에는 검색한 단어만 전송되며, 사용자를 식별할 수 있는 정보는 포함되지 않습니다.

6. 문의하기 기능

설정 화면의 "문의하기"로 의견을 보내는 경우에 한해, 다음 정보가 문의 접수 서버로 전송·저장됩니다:

  • 문의 분류 (오류 / 건의 / 질문 / 기타)
  • 사용자가 작성한 문의 내용
  • 앱 버전, 기기 종류(Android / iOS)

문의는 익명으로 접수됩니다. 계정 정보나 기기 고유 식별자를 함께 보내지 않으므로 작성자를 특정할 수 없으며, 같은 이유로 개별 답변은 드리지 못합니다. 문의 내용은 앱 개선 목적으로만 이용합니다.

작성자를 알 수 없는 구조이므로, 문의를 보내신 뒤에는 해당 문의 건에 대한 열람·정정·삭제 요청을 처리할 수 없습니다. 이 점을 감안하여 문의 본문에 이름·연락처 등 개인을 알아볼 수 있는 정보는 적지 말아 주세요.

보관 기간: 접수일로부터 1년. 기간이 지난 문의는 파기합니다.

처리위탁 및 보관 위치: 문의 접수 서버는 Vercel Inc.(호스팅)과 Supabase Inc.(데이터베이스)를 이용하며, 데이터베이스는 대한민국(서울) 리전에 저장됩니다. 서비스 제공 과정에서 국외에 소재한 서버를 경유할 수 있습니다.

7. 데이터 보관 및 삭제

기기에 저장된 데이터(제2항)는 앱을 삭제하면 함께 삭제됩니다. 앱 내에서 개별 단어, 카테고리 등을 직접 삭제할 수도 있습니다. 문의 내역의 보관·파기는 제6항을 따릅니다.

8. 아동의 개인정보 보호

본 앱은 13세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다.

9. 개인정보처리방침 변경

본 방침은 변경될 수 있으며, 변경 시 앱 업데이트 또는 본 페이지를 통해 공지합니다.
