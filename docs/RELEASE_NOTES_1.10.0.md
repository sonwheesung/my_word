# 1.10.0 출시 노트 (versionCode 27)

Play Console `프로덕션 → 새 버전 만들기 → 출시 노트` 에 언어별로 넣는다.
등록정보 언어가 **ko-KR · en-US · ja-JP** 세 개라(2026-10-28 API 실측) **세 언어 모두 있어야 출시할 수 있다.**

- 언어당 상한 500자. Play 콘솔은 서식을 지원하지 않는다
- 🔴 **사용자가 올라오는 자리는 1.7.0 이다.** 1.8.0·1.9.0·1.9.1·1.9.2 는 전부 내부 테스트에서만
  돌았으므로, 이 노트는 **네 버전의 변화를 함께** 담는다. "구독만 추가"로 적으면 틀린다
- 🚫 R8 · SQLite 이사 · 성능 수치 같은 내부 사정은 적지 않는다(`CLAUDE.md` R8 절)
- 🔴 **한국어 문안은 검수 대상이다**(`common/KOREAN_WRITING.md`). 사장님 검수 전 초안이다
- 집안 문체를 1.7.0 노트에 맞췄다: `•` 불릿 · 한국어는 **~습니다** · 앱 안의 이름을 그대로 쓴다

## 🔴 적지 않은 것 — 코드와 한 줄씩 대조해 걸러냈다

1.7.0 때 *"좌우로 밀면 다음 단어로 넘어갑니다"* 가 실제 동작과 달랐던 적이 있다. 그래서 이번에는
쓰려던 줄을 코드에서 먼저 확인했고, **셋이 걸려 빠졌다**:

| 쓰려던 말 | 왜 뺐나 |
|---|---|
| 「폰을 잃어도 단어를 되찾을 수 있습니다」 | 🔴 **복구 화면이 꺼져 있다.** `syncService.ENABLED_KINDS = ['words']` 이고 `restoreService.RESTORE_READY` 는 넷이 다 켜져야 참이다. 지금은 화면 자체가 안 나타난다 |
| 「문의하면 앱에서 답변을 볼 수 있습니다」 | 🔴 `SupportScreen` 주석이 스스로 *"이 릴리스에는 답변을 보는 화면이 없다. 「답변을 받을 수 있다」고 쓰지 않는다"* 라고 적어 두었다 |
| 「단어가 많아도 빨라졌습니다」 | 숫자로 재 본 적이 없다. 재지 않은 것을 적지 않는다 |

## ⚠ 일본어 이름이 앱 안에서 갈려 있다 (노트와 별건 · 2026-10-28 발견)

```
AI テスト   3곳   ← 홈 띠의 기능 이름. 사용자가 보는 이름이다
AI試験      5곳   ← 그중 2개는 2026-10-28 에 내가 늘린 것이다
```

원래 갈려 있던 것을 늘렸다. **노트는 사용자가 보는 이름(`AI テスト`)으로 쓴다.**
🙋 앱 쪽 정리는 사장님 결정 사항이다 — **지금 고치면 재빌드(vc28)로 끝나고, 출시 뒤에 고치면
OTA 가 일반 사용자 전원에게 가므로 승인 항목이 된다.** 출시 전에 묶는 쪽이 싸다.

## 각 줄의 근거 (검수용)

| 줄 | 근거 |
|---|---|
| AI 시험 추가 | 홈 맨 아래 전용 띠(`HomeScreen` 429행). 앱 이름 ko `AI 시험` · en `AI Exam` · ja `AI テスト` |
| 무료 10번 | `common_server/lib/ai-policy.ts` `FREE_EXAM_QUOTA = 10`. 주체당·평생 |
| 지난 시험 다시 풀기 무료 | 구독 관리 화면 「지난 시험 다시 풀기는 계속 무료」 · 페이월 혜택 3번째 줄 |
| 날마다 새 문제 | 2026-10-28 에 「판수 제한 없이」에서 바꾼 그 문구. 하루 캡은 **새 문제 만드는 호출**을 센다 |
| 광고가 사라집니다 | `PurchaseContext` 의 `hidden = ownsLifetime \|\| pro`. 구독 중 광고 없음 |
| 설정에서 해지 | `SettingsScreen` 구독 줄 → `SubscriptionScreen` → Play 로 보냄(확인 한 번) |
| 해지해도 기간 끝까지 | 페이월 고지 문구와 같은 말 |
| 구글 로그인 | `SettingsScreen` 계정 절. 🚫 백업·답변은 약속하지 않는다(위 「적지 않은 것」) |
| 속도와 반응 | 1.9.2 에서 두 화면이 손을 뗀 상태로 CPU 130~158% 를 쓰던 것을 고쳤다 |
